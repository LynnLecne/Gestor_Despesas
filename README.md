# Gestor de Despesas Pessoais 💰

Uma aplicação web simples para gestão e controlo de despesas financeiras diárias, com persistência de dados na nuvem e suporte para temas claro e escuro.

## 🚀 Funcionalidades

- **Registo de Despesas:** Adiciona descrição, valor e categoria (Alimentação, Habitação, Lazer, etc.).
- **Gestão Completa (CRUD):** Permite listar, editar e eliminar despesas em tempo real.
- **Filtros por Categoria:** Visualização segmentada do total de gastos por setor.
- **Modo Escuro:** Alternância dinâmica de tema (Dark/Light Mode) com preferência guardada.
- **Integração com Supabase:** Armazenamento persistente e seguro na nuvem.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS - manipulação nativa do DOM)
- **Backend/Base de Dados:** [Supabase](https://supabase.com) (PostgreSQL)

## 📦 Como Executar o Projeto

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Abrir no VS Code:**
   Abre a pasta do projeto no Visual Studio Code.

3. **Executar a aplicação:**
   Utiliza a extensão **Live Server** do VS Code para abrir o ficheiro `index.html` no teu navegador (geralmente em `http://127.0.0.1:5500`).
